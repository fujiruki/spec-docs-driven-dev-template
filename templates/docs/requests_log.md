# 要望台帳 (requests_log.md)

運用開始日: YYYY-MM-DD

ここは仕様が確定した要望の全記録。実装前の要望も、実装中・検証中・完了・見送りの要望も、同じ要望IDで追跡する。

## 状態

`仕様化済み` / `実装中` / `検証中` / `完了` / `保留` / `見送り` / `取り下げ` / `他要望へ統合`

状態や根拠を更新しても、原文・要望ID・過去の判断を消さない。必要な訂正は追記で残す。

`他要望へ統合` は、別の要望IDに実装や仕様をまとめる時だけ使う。その場合は統合先のR-IDと理由を必ず残す。Gitのマージはこの状態を意味せず、通常は `完了` の根拠として記録する。

---

## 記録テンプレート

```markdown
## R-0001 — 仕様化済み

- 受付日: YYYY-MM-DD
- 最終更新: YYYY-MM-DD
- 原文: ログイン機能にGoogleアカウント対応を追加してほしい
- 仕様反映先: `spec/02_機能仕様.md`（F-03）
- 受け入れ条件: Googleアカウントでログインできること
- タスク: `tasks/R-0001.md` または `task.md` のR-0001
- 実装・検証根拠: （実装・検証時に追記）
- GitHub: Issue #123 / PR #456（使う場合）
- 関連要望: R-0014（あれば）
- 更新履歴:
  - YYYY-MM-DD: 仕様化済み。仕様とタスクを作成
```
