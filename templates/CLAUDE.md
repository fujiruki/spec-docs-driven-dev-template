- 会話で受けた要望は、仕様の検討を始める前に `docs/requests.md` へ原文のまま記録する

- 要望IDの採番、状態の変更、公開範囲、他要望への統合は、すべて `SDDD.md` の規則に従う
- Claude Code の補助コマンドを使える場合は `.claude/commands/` を使う。ただし、コマンドの説明より `SDDD.md` を優先する
